# Instrucțiune instalare XTTS v2 — GiftHub Persona

## Ce s-a schimbat:
Am înlocuit Chatterbox TTS cu **Coqui XTTS v2** — gratuit, open-source, suportă română cu expresivitate emoțională ridicată.

## Pași simpli:

### 1. Instalezi pachetele noi (o singură dată):
Deschori terminalul în GiftHub și scrii:
```
pip install -r requirements.txt
```

### 2. Pornești serverul de voce:
Într-un terminal scrie:
```
python tts_server.py
```

### 3. Reboot Streamlit:
Restartezi aplicația Streamlit din GiftHub (reboot sau refresh).

### 4. Testezi:
Încarci o mostră audio pentru un personaj → scrie un mesaj → auzi vocea clonată pe română cu emoții! 🎤
